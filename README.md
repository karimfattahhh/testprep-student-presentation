# TestPrep Student Presentation

The live presentation TestPrep (by House of Prep) gives to students in grades 10–12, built as a website.

- Open `index.html` (or the GitHub Pages link) in a browser.
- **→ / Space** next · **←** back · **N** presenter notes · **F** full screen.
- Interactive slides (intro, House of Prep, the 7 steps, Elmy, Spot the Glitch) step through on → before moving on.
- `build-form.gs` builds the student sign-up Google Form (run once from script.google.com).
