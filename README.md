# TestPrep Student Presentation

The live presentation TestPrep (by House of Prep) gives to students in grades 10–12, built as a website.

- Open `index.html` (or the GitHub Pages link) in a browser.
- Order: hook (intro, today, Nizar) → the SAT (what, why) → Spot the Glitch → how we work (engine, Elmy) → proof (who we are, legacy, numbers, House of Prep) → the challenge → close. Slides move down; "How we work" moves sideways into the Performance Engine, and "Our legacy" moves sideways into the numbers. **→ / ↓ / Space**, scroll or swipe = next · **← / ↑** = back · **N** presenter notes · **F** full screen · click the logo to return to the start.
- Interactive slides (intro, House of Prep, the 7 steps, Elmy, Spot the Glitch) step through on → before moving on.
- `build-form.gs` builds the student sign-up Google Form (run once from script.google.com).
